# Getting started

## User installation guide

Install `barotropy` from PyPI using pip:

```bash
pip install barotropy
```

Verify the installation:

```bash
python -c "import barotropy; barotropy.print_package_info()"
```

If successful, the console will display the package banner and version information.

To work on the source code, follow the [developer installation guide](developer_guide.md#installation-from-source).
